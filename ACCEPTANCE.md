# Acceptance & Shipping Checklist

## Product
- [ ] Core ICP can complete the primary job without operator intervention.
- [ ] User onboarding succeeds on mobile and desktop.
- [ ] Billing is enabled and testable.
- [ ] Customer data export works.
- [ ] Support/admin tooling exists.

## Engineering
- [ ] CI green.
- [ ] Migration from clean database works.
- [ ] Tenant isolation tested.
- [ ] Critical API contracts tested.
- [ ] No secrets in repository.
- [ ] Error tracking configured.
- [ ] Backups + restore tested.
- [ ] Rate limits configured.

## Integration
- [ ] Partner credentials validated.
- [ ] Webhook signatures verified.
- [ ] Retry/reconciliation verified.
- [ ] Provider outage behavior documented.

## Shipping
- [ ] Production smoke suite green.
- [ ] Monitoring dashboards live.
- [ ] Rollback procedure tested.
- [ ] Terms/privacy/support contacts live.
- [ ] Customer onboarding SOP ready.
